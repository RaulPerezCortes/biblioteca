# My Book Library

A simple web application to manage your personal book collection, built with Next.js.

## Features

- Add new books with title, author, genre, year, and description
- View your book collection
- Search books by title or author
- Delete books from your collection
- Data persists in local storage

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the application.

## Usage

- Click "Add Book" to add a new book to your library
- Use the search bar to find books by title or author
- Click "Delete" on a book to remove it from your collection

## Technologies Used

- Next.js 16
- TypeScript
- Tailwind CSS
- Local Storage for data persistence
